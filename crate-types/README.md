# crate-types

The website's docs/types.html usage snippet, made runnable.
XTypes 1.3 section 7.6.3: two identical primitive TypeIdentifiers are assignable.

## Run it

```sh
cargo run
```

Path deps into the local zero-dds checkout: `zerodds-types`.

Output of the run this README was written from:

```
types: Int32 writer and Int32 reader match
```
