# `derive(DdsType)`: a topic type defined in Rust

The other route of GitHub #33: the type is defined in Rust and the IDL is
exported from it, for C, C++ and every other vendor. `Track` holds a
date-time group (`src/dtg.rs`) that cannot hold an invalid one and a
`NonZeroU32` key; on the wire they are an IDL `string<12>` and an
`unsigned long`.

```rust
#[derive(WireRepr)]
#[wire(idl = "string")] // reads through TryFrom<&str>, writes through Display
pub struct Dtg { /* … */ }

#[derive(DdsType)]
#[dds(name = "app::Track", extensibility = "final")]
struct Track {
    #[dds(key)]
    id: NonZeroU32,
    #[dds(bound = 12)]
    at: Dtg,
    #[dds(bound = 8)]
    seen: Vec<Dtg>,
    #[dds(bound = 16)]
    callsign: String,
}
```

`Track` also holds a union and a generic type:

```rust
#[derive(DdsType)]
#[dds(name = "app::Pair_{T}", extensibility = "final")]
struct Pair<T> { first: T, second: T } // Pair<f64> is app::Pair_double

#[derive(DdsType)]
#[dds(name = "app::Position", extensibility = "final", discriminator = "i16")]
enum Position {
    #[dds(case = 1, name = "grid")]
    Grid(String),               // case 1: string grid;
    #[dds(case = 2, name = "latlon")]
    LatLon(Pair<f64>),          // case 2: ::app::Pair_double latlon;
}
```

`TrackView<'a>` is the same IDL type with `callsign: &'a str`: decoding it
lends the call sign out of the received sample instead of copying it.

`Track::idl()` is `idl/track.idl`. `build.rs` compiles that file through
`zerodds-build` with `rust_type` for `at` and `id` — the IDL route of
[`rust-type`](../rust-type) — and `cargo run` checks that both routes give the
same `TypeIdentifier`, the same `TypeObject` and the same octets, then
shows a sample rejected with its reason: a peer that holds the IDL
`string` sent `noon`.

```sh
cargo run
sh peer/run.sh   # the C peer, generated by zerodds-idlc from idl/track.idl
```

## Dependencies

The crates of GitHub #33 (`zerodds-codec`, `zerodds-derive`, `rust_type`
in `zerodds-build`) are newer than the latest crates.io release. The path
dependencies reach into a ZeroDDS source tree that holds this repository,
the layout of `ci/run-examples.sh` (see the repository README). With RC8
the example switches to the published crates.
