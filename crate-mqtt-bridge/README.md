# crate-mqtt-bridge

The website's docs/mqtt-bridge.html usage snippet, made runnable.
MQTT 3.1.1 section 4.7.1: the single-level `+` and multi-level `#` wildcards.

## Run it

```sh
cargo run
```

Path deps into the local zero-dds checkout: `zerodds-mqtt-bridge`.

Output of the run this README was written from:

```
mqtt-bridge: both wildcard filters matched
```
